# Figures

Pilot and final plots are separated by run directory. All performance plots are generated by scripts/evaluate.py from exported CSVs. `workflow.png` illustrates the actual processing order, `performance.png` shows test P/R/F1 at validation-F1 thresholds, `precision_recall.png` shows full test PR curves, `confusion_matrices.png` shows counts and row fractions, and `fpr_operating_point.png` contrasts validation/test behavior at the constrained thresholds.
